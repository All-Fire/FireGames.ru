3. Data collected directly by the developer

According to the developer's current information, the game does not use a separate web or mobile analytics service and does not create player accounts. The developer does not operate a server database of gameplay history, player profiles or progression analytics.

Game progress, settings and in-game values may be stored locally on the device to make the game work. These local data are not sent to the developer unless a future online feature is introduced and disclosed to users.

If a user emails the developer, the sender's email address and the contents of the message are processed only to respond and handle the request. The correspondence is kept only as long as reasonably necessary to respond, resolve the issue and protect legal claims.

4. Advertising and Yandex Mobile Ads SDK

The game uses the Yandex Mobile Ads SDK (Yandex Ads) to request and display advertisements. SDK operation may involve data being transmitted to Yandex and its advertising partners. Depending on the SDK version, device, available permissions and configuration, this may include:

  • IP address and technical network connection information;
  • Android advertising ID (GAID) or another device identifier, if available and permitted;
  • device model and technical characteristics, operating-system and app version;
  • mobile-network details and type of internet connection;
  • technical events needed to request, display and measure ads and prevent invalid impressions or clicks.

Purposes may include delivering ads, limiting ad frequency, measuring ad performance, securing the advertising system and preventing fraud. The developer does not use a separate analytics service to analyse gameplay activity.

For details about data, purposes, recipients and retention by Yandex, see the Yandex Advertising Services Privacy Policy and Yandex Privacy Policy. Yandex determines and is responsible for processing carried out within its own services under its published documents.

5. Location and permissions

In the default configuration, Yandex Mobile Ads SDK does not collect precise or approximate location automatically. The developer does not intend to transmit a user's location to the advertising SDK. If a future version adds such a feature or enables the relevant SDK setting, it will be done only with the required permissions and legal basis, and this Policy will be updated before that processing begins.

The game should request only Android permissions needed for its functions. The actual permission list must be checked against the release build manifest.

See Yandex Android SDK GDPR guidance.
